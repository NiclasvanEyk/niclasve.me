# Fonts for the OpenGraph images

Satori needs raw TTF/OTF font data; `.woff2` files (which is everything
`@fontsource-variable` ships) are not supported.

Both files are latin subsets and licensed under the SIL Open Font License:

- `Merriweather-Black.ttf` — Merriweather Black (900)
  <https://cdn.jsdelivr.net/fontsource/fonts/merriweather@latest/latin-900-normal.ttf>
- `JetBrainsMono-Regular.ttf` — JetBrains Mono Regular (400)
  <https://cdn.jsdelivr.net/fontsource/fonts/jetbrains-mono@latest/latin-400-normal.ttf>
